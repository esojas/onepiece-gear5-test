## About
This project is a simple combat-oriented game inspired by my personal vision of how Gear 5 should feel and play in a video game.

## Features
- Charged grapple attack with momentum-based movement
- IK-driven stretchy limbs

## Main Controls
- [WASD] — Movement
- [LeftShift] — Sprint
- [LeftClick] — Charge Punch Attack
- [RightClick] — Charge Kick Attack
- [F] — Fly momentarily 

- [E] — Pick up Lightning
### Lightning Mode
- [LeftClick] — Throw Lightning
  
- [Q] — Charge Grapple
### Grapple Mode
- [LeftClick] — Grapple Closer
- [RightClick] — Grapple Further
- [Q] — Let Go Grapple
